The sea-glass look, everywhere — and this is what each device sees

The material is now defined once, in SeaGlassSupport.kt, and every surface in the app is cut from it: SeaGlassLook holds the values, seaGlassSurface(fill, shape, corner) is the single entry point, and it picks the path for the device — the sampled pane on API 33+, the painted pane below it. Before this, five different tunings existed (0.44/0.70 login pills, 0.38/0.66 guest pill, 0.40/0.72 panels, 0.62/0.45 onboarding, 0.44/0.70 hero), so the same glass read at a different strength on every screen. It is now 0.62 density / 0.45 transparency everywhere — the denser end, which is the one you picked.

4 — The one definition

Everything above resolves to this, and only this:

object SeaGlassLook {
    const val TintDensity   = 0.62f      // how much of the tint the body absorbs
    const val Transparency  = 0.45f      // how much of the backdrop survives
    const val Coarseness    = 0.28f
    const val FrostRadiusDp = 26f
    const val ThicknessDp   = 15f
    const val RimChalkiness = 0.55f

    // the painted pane, at the same strength as the sampled one
    const val BodyTopAlpha = 0.58f
    const val BodyBottomAlpha = 0.34f
    const val HighlightAlpha = 0.22f
    const val BounceAlpha    = 0.08f
    const val RimAlpha       = 0.32f
    val RimWidth = 1.dp
}

@Composable
fun seaGlassSurface(fill: Color, shape: Shape, cornerRadius: Dp): Modifier =
    if (LocalInspectionMode.current || !seaGlassSurfacesAvailable) {
        Modifier.seaGlassFallback(fill = fill, shape = shape)   // API < 33, and previews
    } else {
        Modifier.seaGlass(material = seaGlassMaterial(fill, cornerRadius.value), …)
    }

5 — Turn the dial here

Lighter or heavier, one place. If the wide panels now read as too solid — they were 0.72 transparency before and are 0.45 now — that is the number to move, and moving it moves every surface in the app together.

6 — One thing to know about previews

A Compose tooling preview takes the fallback path on every API level, because a preview has no GPU pass to sample. So a @Preview of any of these surfaces always shows you what Android 10 sees — never the frosted version. Use the toggle above to see the other one.
