Dynamic colour removed, and the animated canvas now survives a trip to the background

Two changes, shown before anything is compiled. Section 1 is the settings row that goes away. Section 2 is a working simulation of the canvas bug and the fix — press Send to background then Return in each mode and watch the state panel.

1 · Dynamic colour, removed

The row sat in Settings → Appearance and was wired to Material You wallpaper sampling. It only ever applied to the classic look, which the design style no longer uses — so it was a switch that could not visibly do anything. The row, its preference read, and the theme branch behind it are all gone. The scheme always comes from your seed colour now.

2 · The canvas that did not come back

Backgrounding the app killed the animated canvas on both surfaces — the player and the Spotlight card — and it stayed dead. Two separate poisoning layers were behind it, and the second one is the reason a restart was the only cure.

What the old code did

  • Stopping the app released the window, and the TextureView surface with it — while the player was still bound to it. The renderer reported an error about a surface that no longer existed.
  • That error was read as a clip failure. Three of them emptied the retry budget.
  • The last one wrote UNPLAYABLE against the URL for 30 minutes.
  • Worse: the next lookup then saw every provider offer that same, now-refused URL. Refusals counted as answered, so the lookup concluded "this song has no canvas" — and that flag lives in memory for the whole session.
  • Result: canvas dead on the player and the Spotlight card, and only a restart cleared the second flag.

What the fix does

  • Detach before the window dies. setVideoTextureView(null) on ON_STOP, so the renderer has no dead surface to complain about.
  • A settle window. For 1.5 s after returning, an error is read as "the surface is still coming up", spends no retry, and writes no URL verdict.
  • Fresh budget on return. Whatever failed, failed on a window that no longer exists.
  • A dead-URL refusal is no longer a definitive miss. That verdict expires, so the song gets asked again instead of being written off for the session.
  • First frame on a hidden window no longer claims ready, which stops the canvas fading in over an empty surface.
