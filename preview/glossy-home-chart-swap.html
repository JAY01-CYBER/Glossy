Greeting header · search icon & letter avatar removed

The name row used to end with two buttons: a search icon and a circular avatar showing the first letter of the account name. Both are gone — the header is now just the greeting and the name.

Search is still one tap away: the floating bottom bar keeps its own Search pill, and the Library tab has its search action. Account settings remain in Settings.

What changed

Two files touched. Nothing else in the app references the removed pieces.
FileChange
viewmodels/HomeViewModel.kt − HomeSection.Charts (unconditionally added to every Home feed)
+ HomeSection.NewReleases — added only when explorePage.newReleaseAlbums is non-empty (the Chart section rendered even when the network had nothing)
+ inherits the Chart section's old shuffle weight (500) and default position (85), so it sits in the same premium slot near the top
ui/screens/HomeScreen.kt − ChartCard + RegionChip composables, ChartRegions list, the whole HomeSection.Charts render branch, and the now-unused TrendingUp import
+ HomeSection.NewReleases branch: a "New release albums" header that opens the existing new_release screen, and a carousel of album art using the same ytGridItem tiles as the other Home shelves
ui/component/GreetingSection.kt − the header's search icon (GlossyIconAction) and the initial-letter avatar (GlossyInitialAvatar), plus the nav controller, tint, and six imports that only served them (~34 lines)
+ header now renders only the greeting and the name — shared components untouched for MiniPlayer/Library/Settings
ui/screens/Screens.kt + doc comment corrected: Search rides the floating bar's pill (the header no longer hosts it)

Why "New releases"

  • Zero new network code. The Home view model already downloads the Explore page — which includes newReleaseAlbums, already filtered for hidden-explicit preference — so the shelf costs nothing extra to fill.
  • Reuses existing plumbing: the new_release route, NewReleaseScreen, the localized new_release_albums string, and the standard album tile renderer.
  • Nothing else was removed. The Charts screen itself, the Explore page's chart rows, and the region picker there are all untouched — only the Home-feed shortcut is gone.
